----PROYECTO ANÁLISIS FORENSE----

El proyecto adjunto presenta el enunciado de una famosa actividad típica en proyectos de análisis 
forense que introduce diversos casos y supuestos con ejercicios y preguntas a resolver. 
Los archivos adjuntos constituyen la forma de resolver el reto. A continuación un resumen de los 
documentos incluidos, indicando el orden recomendado de importancia y lectura para interpretar 
correctamente el ejercicio y su resolución:

- MAIN_PROY.PDF --> Constituye el documento principal y por él se debe empezar. En él se encuentra
	 el enunciado del proyecto junto on las respuestas directas. Parte de la metodología para 
	obtener dichas respuestas se encuentra en el mismo documento: de lo contrario, 	quedará 
	indicado dónde encontrarlo, que constituye el resto de los archivos de este proyecto.
- Informe_Australia.PDF --> Documento adicional y complementario que relata el proceso, resultados
	y metodología recogidos en la fase del proyecto relacionada con el incidente de Australia. 
	Se recomienda leerlo cuando lo indique el documento principal.
- pcap_analyzer.py y README_pcap_analyzer.md --> Constituyen un script de análisis de capturas de 
	paquetes en formato pcap y su documento	README. Ambos forman parte de una de las soluciones
	 a uno de los ejercicios planteados, se recomienda abrirlo y probarlo cuando lo indique el 
	documento principal, empezando por el README propio del script.
